# 设计风格词汇与 AI 通病清单

> 来源：`cc-base/.claude/skills/design-brief-builder/references/style-vocabulary.md`（整件采用）。
> 定位：把形容词翻成可执行方向；认出"给任何页面都会给的默认"。锚点产品迭代快，用前先搜当前公认做得好的。

## 风格词汇（气质 / 适合 / 不适合 / 注意）

| 风格 | 气质 | 适合 | 不适合 | 注意 |
|---|---|---|---|---|
| 瑞士极简/编辑网格 | 严谨网格、大留白、克制字重、对齐即结构 | 内容阅读、文档、品牌站、专业工具 | 强引导消费流程 | 易平庸，大胆放一处 |
| 数据密集工作台 | 32px 表格、发丝线、tabular-nums、状态点 | 仪表盘、后台、运维、金融 | 首次使用的消费者 | 密度由内容受众定 |
| 纸感/E-ink | 暖纸底、单墨、明度即层级、无阴影 | 案头工具、审核、标注 | 多色语义实时监控 | 语义靠形状不靠颜色 |
| OLED 深色工作区 | 近黑底、发丝线、极少彩色 | 开发工具、剪辑、久盯屏 | 户外强光操作端 | 深色不是浅色反转 |
| 玻璃拟态 | 半透明层、折射景深、材质感 | 系统 chrome、首屏英雄区 | 密集内容、低端机 | 只用于 chrome 与英雄时刻 |
| Material 3 Expressive | 动效 token、动态色、表现性形状 | Android 原生、消费 app | 桌面专业工具 | 动效有物理模型 |
| 新野兽派 | 粗黑边、高对比、大字、生硬对齐 | 创意品牌、潮流、活动页 | 企业后台、金融 | 丑得有意需极高控制力 |
| Bento 网格 | 模块化卡片、不等分网格 | 功能聚合页、营销站 | 长流程、表单 | 极易落入 SaaS 卡片通病 |
| 终端 CLI | 等宽、ANSI 色、box-drawing | 命令行工具、编程 Agent | 消费者 | 80 列坍塌要定 |

用户点名风格先追问"要的是它哪一点"，只学一点，不整套抄。

## 参考锚点对（二选一用）

密度 Linear 紧凑 vs Notion 宽松；温度 Stripe 冷 vs Airbnb 暖；正式 Bloomberg 严肃 vs Figma 活泼；层次 Apple 极简 vs Vercel 密而干净；导航 Slack 侧栏 vs Spotify 底 Tab vs Raycast 命令面板；主题 GitHub 深 vs Google Docs 浅；圆角 iOS 大圆角 vs Windows 直角；AI 产品 Claude 对话+画布 vs Perplexity 引用优先。

## 感受 → 属性补充

- 「安静/沉稳」→ 低饱和、小字号差、慢而少的动效、无装饰图形。
- 「有生命」→ 一处响应用户动作的动效，不是每段淡入。
- 「专业」→ 先问哪种：TED 温和权威、Apple Keynote 神圣感、麦肯锡数据冷静。
- 「像手写/有人味」→ 暖底、人文字体、不规则留白；不是手写字体。

## AI 生成界面的通病（默认不是选择）

brief 钉死的照 brief；没钉死的轴不许落在这上面。生成后逐条对照，命中就说出改了什么。

五类聚簇：① 奶油底 + 高对比衬线大标题 + 陶土橙强调；② 近黑底 + 单一酸绿/朱红；③ 报纸式（发丝线零圆角密栏）；④ SaaS 卡片套件（一律圆角一律灰影渐变装饰）；⑤ 模板装饰（ALL-CAPS 眉标、中点串、破折号标签、冒充黑、等宽小标签、按钮尾巴→）。
排版：单字换色斜体、标签全大写、多余说明标签、非序列用 01/02/03。
动效：每段淡入上滑、每卡悬停过渡——只留一处编排好的时刻。
布局：过度居中、紫色渐变、一律圆角、Inter 当个性。
首屏：大数字+小标签+支撑统计+渐变强调——先问这个产品世界里最有特征的东西是什么。

## 2026 趋势注记（只当校准）

扁平地基 + 只在 chrome 与英雄时刻用玻璃/表现性动效；token 按意图命名三层；欧盟无障碍法案下 AA 是地板；Agent 产品审批只在不可逆处、AI 活动有专属视觉语言。
